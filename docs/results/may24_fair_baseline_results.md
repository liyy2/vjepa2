## Headline

Against the fair kinematic-only baseline, V-JEPA OOF probabilities improved mean QWK:

| Comparison | Mean QWK | Delta | Positive folds | Seed-fold wins |
| --- | ---: | ---: | ---: | ---: |
| kin_only | 0.3615 +/- 0.0429 | - | - | - |
| kin_only + V-JEPA OOF | 0.4090 +/- 0.0794 | +0.0475 | 4/5 | 35/50 |

The pooled paired Wilcoxon test over the 50 fold x seed pairs is one-sided
`p=6.227e-05` for `kin_only + V-JEPA OOF > kin_only`.

The stricter fold-mean Wilcoxon test over 5 paired folds is `p=0.09375`.
Use the result as a positive reproducible finding, but do not describe it as
fold-level significant without this caveat.

## What is clean in this comparison

The fair `kin_only` feature set excludes:

- raw diagnosis column `dx`
- diagnosis one-hot columns `dx_*`
- all item 3.5 columns `item35*`
- non-kinematic manifest metadata such as `frame_count_manifest`
- identifiers such as subject, visit, side, clip path, and label

The V-JEPA features are 5 OOF probability columns per clip, generated by an
inner subject-disjoint combiner and joined back by `clip_path`. The join code
now fails on missing, duplicate, or silently unmatched OOF rows.
