What The Results Say

The main diagnosis has shifted from “not enough frames” to “wrong temporal readout for subtle finger motion.”

Adaptive coverage alone did not unlock performance.

The fixed K=4 setup under-samples long clips, but full adaptive coverage did not close the gap. It often preserved short-clip behavior and degraded mid/long clips, which points to temporal dilution.

The fixed scorer has per-window ordinal signal.

WindowMIL top-k pooling improves QWK over plain adaptive embedding heads. The useful signal appears concentrated in selected windows rather than in whole-clip means.

Learned adaptive heads are mostly collapsing.

Stats MLP, TemporalAgg, and XceptionTime over adaptive embeddings are often class-prior or near-prior predictors. Token-level statistics did not fix that.

Cached temporal V-JEPA is stronger than the attentive probe.

The temporal-stats stacker reaches much higher QWK than the fixed attentive CORN head, especially when probabilities are selected with subject-group inner OOF.

V-JEPA is complementary to kinematics.

Honest fold-0 fusion nearly matches the kinematic QWK baseline, and validation-tuned diagnostics can exceed it. That argues against the V-JEPA signal being useless or fully redundant.

Five-fold confirmation is still missing.

Fold-0 has only 66 validation clips. Small seed and threshold differences are unstable until the subject-level five-fold protocol is run end to end.

Fixed-best adaptive full coverage 75.0 / 0.816 41.3 / 0.331 12.5 / 0.184 Full coverage preserves short clips but worsens longer clips.

The adaptive dataset patch is doing the mechanical part correctly: long clips can span the full video, and the capped-window smoke check on a 33.3s validation clip returned 12 starts across the whole clip. The remaining failure is how the windows are scored and pooled.

Next Best Moves

Ordered by practical chance of improving the result or reducing uncertainty.

Let the microbatched JEPA resumes finish

Track the one-GPU epoch-2 salvage chain 28869116-28869120 first, then compare against the full 4-GPU chain 28869066-28869071 when it eventually runs.

Prioritize score-level MIL over embedding means

The best adaptive gains came from per-window severity scores plus top-k/threshold pooling, not from whole-clip embedding aggregators.

Run subject-level five-fold CV

Fold-0 is too small to rank seeds, thresholds, and fusion weights confidently. Move the strict subject-OOF stacker and fusion to all folds.

Add motion-biased inputs or objectives

Finger-tap severity is a temporal motor signal. Frame differences, optical-flow-style channels, or landmark-guided auxiliary losses should be tested.

Use kinematics as a teacher

Distill kinematic severity scores or tap-cycle features into the video model so V-JEPA learns the same fine-grained cues without explicit test-time kinematics.

Stop citing leaky diagnostics as performance

Validation-tuned fusion and threshold rows are useful for diagnosis, but only subject-OOF-selected or held-out train-fitted rows should be treated as claims.
