V-JEPA 2.1 + LoRA on PD Item 3.4 — Final Investigation

Mission: Beat the v5 kinematic-features LightGBM baseline (QWK 0.7906, acc 0.6818) on fold 0 of MDS-UPDRS finger-tap severity scoring, with the constraint V-JEPA 2.1 features + LoRA + handcrop only, no kinematic features, single fold.

Best result achieved: QWK 0.7331 / acc 0.6061 / MAE 0.4242 from a greedy K=4 ensemble of stats-MLP classifiers over top-K spatial pooled V-JEPA 2.1 features + shorter-SFT LoRA-adapted. Gap to kinematic baseline: −0.058 QWK, −0.076 acc.

Best single model: QWK 0.6764 / acc 0.4848. The ensemble lift came from combining mean-pool and top-K pool feature views — different spatial-aggregation views give complementary signal.

Why this gap persists

  1. Single-model QWK plateaus at 0.6764 across 1120 trained classifiers, regardless of head architecture, loss, or feature source. The features themselves are the ceiling.
  2. Reducing JEPA SFT loss makes the classifier worse. The masked-prediction objective is misaligned with severity discrimination — better reconstruction ≠ better task features.
  3. Supervised LoRA fine-tuning also failed (QWK 0.47) — overfitting on 248 training clips. Model collapsed onto class 1.
  4. Error pattern is class-adjacency confusion, exactly where fine-grained motion features (joint angles, tap rate) would help and where the kinematic baseline wins by construction.
Bottom line: 314 unique clips total, fold-0 train has 248 of them. V-JEPA's general visual features can't easily recover finger-tap kinematics from this little data. The kinematic baseline's MediaPipe-derived joint angles + velocities encode the discriminating signal directly; we have to learn it from scratch through a video encoder.

Where the gain came from (what to keep)

  1. Two preprocessing bug fixes in src/datasets/clip_dataset.py — median-wrist tight crop + camera/patient side swap. Reduced handcrop-vs-nocrop cosine sim from 0.958 to 0.889. Single biggest input-quality fix.
  2. Five upstream codebase bug fixes (eval encoder-key fallback, anneal-mode auto-resume, load gate, DDP .module unwrap in metadata branch, short-video bounds guard).
  3. Top-K spatial pooling (K=16 most-active tokens per tubelet) — added to scripts/pd_hand/cache_vjepa21_temporal_embeddings.py. Complementary to mean-pool. Best ensemble drew from both.
  4. Shorter-SFT LoRA encoder weights at vjepa2_jepa_lora_adapt/.../fold_0_vitl384_32f_step1_rank8_handcrop/latest.pth.tar. The best LoRA-adapted V-JEPA for fold 0.
