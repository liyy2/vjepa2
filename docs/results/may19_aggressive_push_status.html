5. Strategy

Where we are. Frozen V-JEPA tops out at QWK ~0.53 regardless of head / pooling / adaptive coverage. The encoder fundamentally lacks the rhythm signal (negative R² predicting kinematic features). The path forward is forcing the encoder to encode rhythm: bigger LoRA + MLP modules + more epochs + tighter crop. That's the aggressive LoRA-FT chain currently running.

Next moves if aggressive LoRA-FT plateaus too:

  1. Direct kinematic regression as primary objective (currently aux). Cancel CORN head entirely, train V-JEPA encoder + linear head to regress the 14 kinematic scalars. Then plug predicted scalars into the same LightGBM that scores QWK 0.728 on the real ones.
  2. Frame-difference input cache (Δframe as RGB channel) — motion is now the dominant signal in the input space.
  3. JEPA SSL LoRA continuation on may19 train clips — different gradient signal, no label leak.
  4. Ensemble of all best heads across all caches (combiner + tstats best of each cache, average probs).
