5-fold leak-free hybrid: kin+dx + V-JEPA-OOF on MDS-UPDRS item 3.4

2026-05-24 · may19 dataset · LoRA-FT rank 16, attn-only, 30 epochs · adaptive cache max=48 · subject-OOF combiner with --no-val-tuning · 10-seed ExtraTrees stacker (n_estimators=1000).

V-JEPA-OOF probs do not improve the leak-free kinematic baseline.
Δ QWK = −0.004 across 5 folds (Wilcoxon p = 0.71, one-sided). The previously reported +0.030 lift on fold 0 was a val-tuning artifact.

What changed vs the leaky comparison

  1. LoRA backbone: use latest.pt (final epoch), not best.pt (selected by val QWK). Removes implicit val tuning of the V-JEPA features.
  2. Combiner training: --no-val-tuning flag returns final-epoch predictions, not the val-QWK-best snapshot. Removes inner combiner's val-tuning leak.
  3. Outer 5-fold: the +0.030 lift was a fold-0 single-point estimate. Across all 5 folds it averages to −0.004.

Stacking variants checked (per fold, no folds gain ≥0.02)

The multiseed sweep also tested vjepa-only, statsOnly, fftOnly, top-16 subsets, and the "old_118" feature set (which contains item-3.5 UPDRS label leak — discarded). None showed a meaningful, consistent lift over kin+dx alone in the leak-free protocol.

What this means for the project

  • kin+dx (clean baseline) remains the publishable lower bound at QWK ≈ 0.54 across 5 folds for item 3.4 finger-tapping.
  • V-JEPA 2.1 features add no signal over kinematic features in this small-N, ordinal-medical regime — consistent with the R² scan finding (V-JEPA features cannot predict scalar kinematic measures, mean R² = −0.117 across 54 configs).
  • The +0.030 fold-0 lift in figure_hybrid_clean_qwk.pdf is invalidated. Should be retracted from any forthcoming write-up.

Next direction (if pursuing further): rather than stacking V-JEPA probs, consider (i) a learned scalar V-JEPA→kinematic distillation as an auxiliary task during LoRA-FT, (ii) per-fold V-JEPA hyperparameter search with proper inner-cross-validation (not the single 30-epoch LoRA-FT recipe used here), or (iii) a different foundation model (e.g., a hand-specific video model). But the current evidence does not justify additional V-JEPA capacity inside the present recipe.
